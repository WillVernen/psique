# PsiQuê

App de apoio ao trabalho clínico em psicologia: pacientes, gravações de sessão, transcrição, resumos, humor e chat com contexto clínico.

## Autor

**Francisco Will Vernen de Sousa Josino**

## Stack

- Django 5
- LangChain + OpenAI
- FAISS (RAG)
- Docker / Gunicorn

## Status

Protótipo em evolução. Código histórico também em [`base_psique_arcane2`](https://github.com/WillVernen/base_psique_arcane2).
